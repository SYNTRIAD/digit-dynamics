a(n) is also the number of fixed points of Wolfram elementary cellular 
automaton Rule 4 on a cyclic lattice of n cells. The fixed-point count 
equals trace(T^n) where T = [[1,1],[1,0]] is the compatibility transfer 
matrix, and since T^n[0,0] = F(n+1) and T^n[1,1] = F(n-1) (Fibonacci 
numbers), we have trace(T^n) = F(n+1) + F(n-1) = L(n) by the standard 
Lucas-Fibonacci identity. - Havenaar, Remco and SYNTRIAD Research, Mar 2026

MATHEMATICAL BACKGROUND:

Rule 4's local update function f: {0,1}^3 -> {0,1} maps neighborhood (L,C,R) 
to 1 only when (L,C,R) = (1,0,0), and to 0 otherwise. For a configuration 
c = (c_1, ..., c_n) on a cyclic lattice to be a fixed point, we require:

  f(c_{i-1}, c_i, c_{i+1}) = c_i  for all i (indices mod n)

This constraint can be encoded as a transfer matrix problem. Define the 
2x2 transfer matrix T where T[a,b] = 1 if the local configuration "ab" 
(two adjacent cells with states a and b) can appear in a fixed point, 
and 0 otherwise. For Rule 4, the compatibility conditions yield:

  T = [1  1]
      [1  0]

The number of fixed points FP(n) equals trace(T^n) because each diagonal 
element T^n[a,a] counts closed walks of length n starting and ending at 
state a. The characteristic polynomial of T is x^2 - x - 1, whose positive 
root is the golden ratio phi = (1 + sqrt(5))/2 = 1.618034.

By the standard matrix power formula for Fibonacci-type recurrences:
  T^n = [F(n+1)  F(n)  ]
        [F(n)    F(n-1)]

where F(n) are the Fibonacci numbers (A000045). Therefore:
  FP(n) = trace(T^n) = F(n+1) + F(n-1)

By the standard Lucas-Fibonacci identity F(n+1) + F(n-1) = L(n) 
(see e.g. Koshy, Fibonacci and Lucas Numbers with Applications, 2001), 
we conclude FP(n) = L(n) for all n >= 1.

This connects cellular automaton fixed-point enumeration to Pisot numbers 
(algebraic integers whose conjugates have modulus < 1).
